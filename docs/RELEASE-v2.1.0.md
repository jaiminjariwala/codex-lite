# Codex Lite v2.1.0

An updated macOS workspace for local AI chat, screenshots, code and browsing.

## What's new

- Google and GitHub sign-in with an encrypted account chooser.
- Logged-out accounts stay in the chooser with a "Sign in again" label. Selecting one starts a fresh browser sign-in; its old session token is removed.
- New first-run setup with optional microphone and Accessibility permissions.
- Removed payments, subscriptions and upgrade screens.
- Local Qwen3.5 9B support for text, code and screenshot understanding.
- Improved web-search answers and expandable source lists.
- Background speech-engine preparation for quicker first-use dictation.
- Better chat and code-panel sizing, and title-bar double-click support.
- File trees appear for project files, not standalone generated code.
- Fixed Google profile pictures, added initials as a fallback, and refined navigation arrows, permission indicators and panel dividers.

## Download and install

Download the arm64 DMG below for Apple Silicon Macs. Open it and drag Codex Lite into Applications.

Existing users: quit Codex Lite before replacing the installed app.

## Before you start

- Sign in with Google or GitHub. No payment or AI API key is required for local AI.
- Local AI models download during setup and require several GB of free space. Performance depends on your Mac's available memory and hardware.
- Microphone and Accessibility permissions are optional.
- This build is unsigned and not notarized. macOS may block it until you explicitly approve opening it in Privacy & Security.
- AI answers and generated code can be incorrect, including answers based on web searches.
- Computer and browser automation remain experimental.
